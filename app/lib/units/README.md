# 캐릭터 모듈

현재 적용 범위는 `unit_lab_main.dart`로 실행하는 독립 캐릭터 테스트 화면이다.
기존 `rts/screen.dart`의 전투 코드는 별도이며 아직 이 모델로 통합하지 않았다.

- `game_unit.dart`: 부모 클래스. 체력, 피해 계산, 공격 쿨다운, 이동 명령, 도착, 정지와 액션 전환.
- `stats.dart`: 공통 기본 상수와 변경 불가능한 기본 능력치.
- `upgrades.dart`: 팀마다 공유하는 공방업 상태. 유닛은 생성 때 수치를 복사하지 않고 현재 레벨로 계산.
- `actions.dart`: 지원 액션, 반복 주기, 반복 여부. 액션 속도에 맞춰 애니메이션 프레임 속도를 계산.
- `characters/`: `GameUnit`을 상속하는 일꾼, 병사, 기마병. 고유 능력치·액션·명령 처리만 정의.
- `movement.dart`, `animation.dart`, `direction.dart`: 공통 이동·애니메이션·방향 계산. 부모 유닛이 소유하고 사용.
- `rendering/`: 스프라이트 로딩·수명 관리와 화면 그리기.
- `unit_lab.dart`: 유닛 생성·선택, 입력과 테스트 UI. 게임 규칙이나 피해 계산을 넣지 않는다.

## 업그레이드 규칙

| 유닛 | 공격 업그레이드 | 방어 업그레이드 | 작업 |
|---|---|---|---|
| 일꾼 | 제외 | 적용 | 채굴·수리·건설 |
| 병사 | 적용 | 적용 | 없음 |
| 기마병 | 적용 | 적용 | 없음 |

같은 팀의 모든 유닛 생성 시 같은 `UnitUpgrades` 인스턴스를 전달한다.
`upgradeAttack()` / `upgradeDefense()` 호출은 기존 유닛과 이후 생성한 유닛에 즉시 적용된다.
상대 팀은 다른 인스턴스를 사용한다. 일꾼은 `canUpgradeAttack`을 재정의해 공업에서 제외한다.

현재 능력치는 테스트용 초기값이며 기마병 전용 이미지와 공격 애니메이션은 아직 없다.
공격은 모델에서 대상·사거리·쿨다운·방어력·체력을 처리한다. 테스트 화면에는 전투 대상이 없다.
수리·건설은 서로 다른 액션이지만 현재는 동작 시연만 하며 자원·건물 규칙은 포함하지 않는다.

새 캐릭터는 `GameUnit`을 상속하고 고유 능력치와 지원 액션을 정의한 뒤 `UnitKind`에 생성 경로를 추가한다.
화면 버튼은 `supports()`를 보고 표시하며, 전용 이미지가 없으면 임시 도형으로 표시한다.

## 채굴·운반과 건물

`EngineerUnit.cargo`는 실제 운반량이며 `hasCargo`는 `cargo > 0`에서 계산한다.
세 번의 타격 후 광물을 채취하고, 커맨드 센터 주변으로 이동해 입고한 뒤 같은 미네랄로 돌아간다.
입고 전에는 보관 자원에 합산하지 않는다. 수동 정지·이동은 가방의 광물을 버리지 않는다.
`world/grid_map.dart`는 건물 칸 점유와 경로 탐색, `buildings/`는 건물 정의,
`resources/`는 미네랄 잔량을 관리한다. 커맨드 센터는 4×3칸을 점유한다. 낮고 긴 외형은 표시 크기만 조절한다. 문은 장식이며 주변에서 입고한다.
`dart tool/check_mining_loop.dart`로 전체 순환·자원 보존을 검증한다.

## 시대별 이미지

현재 사용: `app/assets/units/1900/` (천 모자, 카바이드 램프, 멜빵 작업복).
미래 시대용 보관: `app/assets/units/modern/` (안전모, 바이저, 배낭).
현대 이미지는 저장소에 보관하지만 현재 Flutter 번들에는 포함하지 않는다.

빈 배낭일 때 이동 속도는 100, 금을 운반 중이면 70이다.
`hasCargo`는 실제 적재량에서 계산하며 수동 정지로 금이 사라지지 않는다.
입고 후에는 빈 배낭 이미지와 속도 100으로 돌아간다.
공장 본체는 고정 이미지이고 움직이는 부품만 별도 레이어로 그린다.
공통 카메라 제작 기준과 출처는 `app/design/CAMERA.md`를 참고한다.

## 권총 보병과 산탄병

`SoldierUnit`과 `ShotgunUnit`은 `RangedUnit`을 상속한다. 조준·연속 사격·쿨다운·사격 중단은
공통 처리하고, 명중 계산만 다르게 한다. 권총은 단일 대상, 산탄총은 부채꼴 탄자별 첫 충돌을 계산한다.
각 탄자는 한 대상만 맞고, 같은 발의 피해를 대상별로 합산한 다음 방어력을 적용한다.
공업은 탄자 전체 피해 예산을 올린다. 피해가 적 수에 비례해 무한히 늘어나지 않는다.

산탄 초기 시험값: 최대 피해 28, 탄자 7개, 확산각 60도, 사거리 90,
35부터 거리 감쇠, 최대 거리에서 탄자 피해 계수 0.4, 사격 주기 1초.
`ShotgunUnit`의 `stats`, `spread`, `fireCycleSeconds`와 `ShotgunSpread`의
`pellets`, `arc`, `fullDamageDistance`, `minimumDamageFactor`로 조정한다.
위 값은 역사적 수치가 아닌 게임 테스트용 밸런스다.

보병/산탄병 선택 → 캐릭터 선택 → 표적 클릭으로 연속 사격한다.
바닥 이동·정지로 사격을 취소한다. 산탄병의 근거리 1기 / 원거리 3기 버튼은
위치·표적 체력을 초기화해 같은 조건에서 피해를 비교한다.
실제 명중 대상 수와 피해량은 하단에 표시한다.

`dart tool/check_shooting.dart`로 8방향 조준, 단일·광역 피해, 거리 감쇠,
탄자 차단·방어력·공업·사격 중단·건물 차폐를 검증한다.
